## Enunciado: Sensor de Presença PIR com Iluminação temporizada

O projeto utiliza um sensor de presença PIR para detectar movimento no ambiente e acender um LED automaticamente por um período fixo.

* O Arduino lê o sinal do sensor PIR pelo **pino digital 7**
* Controla o acionamento do LED pelo **pino digital 6**
* Ao detectar movimento (`HIGH`), o LED acende e permanece ligado por **5 segundos** antes de verificar novamente
